# 📈 E-Commerce Funnel Analytics

A comprehensive data-driven exploration of user behavior across a digital retail funnel, focusing on conversion friction, discount efficiency, and device-level performance[cite: 1].

---

## 💡 Executive Summary
Understanding user drop-offs is the backbone of e-commerce optimization. This project breaks down **120,000 user records** across 17 structured features to uncover where potential revenue leaks from the funnel and how promotional strategies shift user purchasing habits[cite: 1].

---

## 🔍 Core Insights & Metrics
* **Funnel Attrition:** Identifies a sharp final conversion drop-off, recording an aggregate loss of **93.18%** from initial entry to a completed transaction[cite: 1].
* **Discount Effectiveness:** Measures the direct trade-off between offering promotional discounts and maintaining healthy Average Order Values (AOV)[cite: 1].
* **Segment Analysis:** Contrasts the conversion behavior of mobile vs. desktop users, alongside new visitors versus returning customers[cite: 1].
